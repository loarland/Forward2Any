过滤条件

格式：路径 操作符 值。路径用点分隔，数字段表示数组下标（如 commits.0.id）。
操作符：eq、ne、gt、lt、contains、not_contains、exists、not_exists、regex、in。
值按 JSON 解析，所以 true、123、[1,2] 都写得出来；裸词（如 push）当作字符串。 以 # 开头的行是注释。

模板转换

可用变量： .Payload（解析后的 JSON；报文不是 JSON 时为 {"raw":"..."}）、 .Raw（原始报文）、 .Source.name / .Source.slug / .Source.kind、 .Headers（入站请求头）、 .TraceID、 .Now
模板里取数组元素要用 {{index .Payload.commits 0}}， 不能像过滤器那样写 .commits.0（那是过滤器的语法，模板里会报语法错）。
